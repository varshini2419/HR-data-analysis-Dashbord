# 👥 HR Analytics Dashboard

## 📌 Project Overview

This project analyzes employee demographics, performance, salary, overtime, and attrition trends using SQL, Excel, and Power BI. The dashboard helps HR teams make data-driven decisions regarding employee retention, workforce planning, and performance management.

---

## 🎯 Objectives

- Analyze employee demographics
- Track employee attrition
- Identify top performers
- Analyze salary distribution
- Monitor overtime trends
- Understand employee satisfaction and career growth

---

## 🛠 Tools Used

- Microsoft Excel
- SQL
- Power BI
- DAX
- Power Query

---

## 📊 Dashboard Pages

### Page 1: Employee Demographics Analytics

Features:
- Total Employees
- Male vs Female Employees

- Employee by Job Role
- Employee by Marital Status
- Employees by Education Field
- Employees by Business Travel

Filters:
- Gender

- Job Role
- Travel
- Distance from Home

## 🗄 SQL Analysis Performed

- Employee Count Analysis
- Gender Distribution
- Department Analysis
- Attrition Analysis
- Salary Analysis
- Job Level Analysis
- Performance Rating Analysis
- Overtime Employee Analysis

Example Query:

```sql
SELECT Department,
COUNT(*) AS TotalEmployees
FROM hrdata
GROUP BY Department;
```

---

## 📈 Key Insights

- Research & Development department has the highest employee count.
- Majority of employees travel rarely for business.
- Overtime employees show different performance trends.
- Salary hikes vary significantly across performance ratings.
- Employee demographics provide valuable workforce insights.
